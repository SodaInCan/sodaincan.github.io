## 🚀 Getting Started
InterActiveMultiSelect is a lightweight plugin that enhances your forms. It allows you to use dropdown menus with checkboxes, radio buttons, and more. This guide helps you download and run the software easily.

### 🌍 Features
- Support for checkboxes and radio buttons
- Group options under headings
- Searchable dropdowns for easier navigation
- Works well with Bootstrap modals
